Sarah Thorne @sarah_ts Reviewer · 2h ago

Using a bounded channel of 128 items is solid to prevent unbounded memory exhaustion, but under peak telemetry spikes, will send().await introduce backpressure into the Actix HTTP worker thread? Have we benchmarked whether 256 or 512 is better suited for 10Gbps ingress?

Bump buffer capacity from 128 to 256 to handle telemetry bursts without worker backpressure.
